# 기출 원본(PDF) 드롭 폴더

여기에 기출 PDF를 넣고 알려주면, 내가 읽어서 파서를 만들고 `content/*.json` 으로 변환한다.

## 넣는 법
1. PDF 파일을 이 폴더(`server/content/raw/`)에 복사.
   - 예: `2024_국가직_9급_일반행정.pdf`, `2024_국가직_9급_정답.pdf`
2. 알려줄 정보:
   - **직렬/급수/연도**: 예) 2024 국가직 9급 일반행정
   - **정답 위치**: 문제 PDF 안에 있음 / 별도 정답표 PDF / 따로 없음
   - PDF가 **텍스트 선택 가능**한지(복붙되는지) — 스캔본이면 OCR 필요

## 처리 흐름
1. 한 파일 먼저 드롭 → 레이아웃 확인
2. 그 레이아웃에 맞는 파서 작성 → JSON 변환 → 너가 정답/오탈자 스팟체크
3. 검증되면 5년치(연도별 파일) 일괄 변환 → `npm run import`

> 변환된 JSON 은 상위 폴더(`content/`)에 `2024-국가직-9급.json` 형태로 생성됨.
> 이 raw 폴더의 PDF는 깃에 안 올리는 게 좋음(.gitignore 권장).
